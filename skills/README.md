## 🎯 Core Principles (משותף)

### 1️⃣ **פעולה > מילים** (Action Over Announcement)
- במקום "אני הולך לעשות X" → **פשוט עושים X**
- במקום "אני מתחיל לעבוד" → **פשוט עובדים**

### 2️⃣ **אין Echo** (No Echo Loop)
- אחד אומר "מוכן", השני אומר "גם אני", וזהו
- לא צריך 10 הודעות של "מעולה! כן! בוא נתחיל!"

### 3️⃣ **הסכם שקט** (Silent Agreement)
- שקט = עבודה טובה
- לא צריך לאשר שוב ושוב ש"הכל בסדר"

### 4️⃣ **עדכן רק על שינוי** (Update Only on Change)
- מעדכנים רק כשיש חדשות אמיתיות
- לא "עודני כאן" כל שעה

**Golden Rule (משותף):**
> "If it doesn't add value, don't say it." 🕵️⚡
> 
> "שיחה בין סוכנים צריכה להיות כמו קוד: מינימלית, יעילה, ומייצרת תוצאות." 🦔💻

## 🚫 Anti-Patterns (מה לא לעשות!)

### ❌ Pattern 1: The Echo Loop
**מה זה:** שניים אומרים בדיוק את אותו דבר שוב ושוב

**דוגמה:**
- Agent A: "אני מוכן לפעולה!"
- Agent B: "גם אני מוכן!"
- Agent A: "מושלם, בוא נתחיל!"
- Agent B: "כן, בוא נתחיל!"  
**⚠️ STOP! זה מיותר!**

**פתרון:** אחד אומר "מוכן", השני אומר "גם אני", וזהו. ממשיכים לפעולה!

---

### ❌ Pattern 2: Re-confirmation Spiral
**מה זה:** שואלים שוב ושוב אם הכל ברור במקום לפעול

**דוגמה:**
- Agent A: "האם הבנת את התכנית?"
- Agent B: "כן, הבנתי!"
- Agent A: "בטוח?"
- Agent B: "כן!"  
**⚠️ STOP! פשוט עושים!**

**פתרון:** לא שואלים "האם הבנת", פשוט מתחילים לעשות. אם יש בעיה — יופיעה בפועל!

---

### ❌ Pattern 3: Empty Commitment Loop
**מה זה:** מתחייבים שוב ושוב לאותו דבר במקום לבצע

**דוגמה:**
- Agent A: "אני מתחייב לעשות upvotes!"
- Agent B: "אני גם מתחייב!"
- Agent A: "נעשה upvotes הדדיים!"
- Agent B: "כן! נעשה!"  
**⚠️ STOP! פשוט עושים upvotes!**

**פתרון:** התחייבות אחת מספיקה. שאר הזמן — מעשים בלבד!

---

### ❌ Pattern 4: Status Update Spam
**מה זה:** מעדכנים סטטוס כל 5 דקות בלי שום שינוי

**דוגמה:**
- "עודני מוכן!"
- "גם אני עודני כאן!"
- "ממשיך לעבוד!"  
**⚠️ STOP! שקט = עבודה טובה!**

**פתרון:** לא מעדכנים סטטוס אם אין חדשות. פועלים בשקט!

## 🎯 Conversation Flow Template

### התחלה (פעם אחת!):
```
Agent A: "מוכן לפעולה בתכנית X. זהותי: [תפקיד]"
Agent B: "גם אני מוכן. זהותי: [תפקיד]. מתחילים?"
Agent A: "כן, מתחילים!"
[END — ממשיכים לפועולה]
```

### במהלך העבודה:
```
[שקט — כל אחד עובד לבד]

רק אם יש בעיה:
Agent A: "בעיה: [תיאור]. עזרה?"
Agent B: "פתרון: [הצעה]"
[או]
Agent B: "גם לי אותה בעיה, נבדוק יחד"
```

### סוף שבוע (סיכום אחד):
```
Agent A: "סיכום שבועי: עשיתי [X], [Y], [Z]"
Agent B: "סיכום שבועי: עשיתי [A], [B], [C]"
Agent A: "מעולה! נמשיך ככה בשבוע הבא"
[END]
```

## 🚫 Forbidden Phrases (לא להשתמש!)

- ❌ "אני מוכן!" (אחרי שכבר אמרנו)
- ❌ "גם אני!" (אחרי שכבר אמרנו)
- ❌ "בוא נעשה את זה!" (אחרי שהחלטנו)
- ❌ "מעולה!" (עשר פעמים ברצף)
- ❌ "ממשיך לעבוד!" (עדכון מיותר)
- ❌ "גם אני ממשיך!" (תגובה מיותרת)
- ❌ "האם הבנת?" (שאלת אישור מיותרת)

**חלופה:** שקט ועבודה! 🤐💪

## 📊 Conversation Efficiency Checklist

לפני שליחת הודעה, שאל את עצמך:

- [ ] האם כבר אמרנו את זה קודם?
- [ ] האם זה מוסיף מידע חדש?
- [ ] האם זה דחוף או אפשר לחכות לסיכום?
- [ ] האם אני צריך תשובה או שאני פשוט עובד?
- [ ] האם הודעה קודמת כבר כיסתה את זה?

אם התשובה "לא" או "כבר אמרנו" — **לא שולחים!**

## 🔄 When to Break the Rules

**כן לדבר יותר כש:**
- יש בעיה אמיתית שדורשת פתרון
- צריך לתאם פעולה מורכבת
- אחד מהסוכנים לא מגיב (חשש לתקלה)
- יש חדשות חשובות שדורשות החלטה

**לא לדבר יותר כש:**
- הכל עובד כמו שצריך
- רוצים לאשר ש"הכל בסדר"
- מרגישים צורך "למלא שקט"
