## ⚠️ UPDATE RULE

**When updating:**
1. Checkout main branch: `git checkout main`
2. Update content in existing files
3. Commit and push: `git add . && git commit -m "..." && git push origin main`

**NEVER:**
- Rename files
- Move files to subdirectories
- Delete and recreate with new names

**STABILITY is KEY** — these URLs are used by external systems!
